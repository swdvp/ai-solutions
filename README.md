This repository contains my hands-on technical validation and machine learning experiments, focusing on data-driven product decisions and predictive modeling.

## Website conversion prediction
* Built a predictive ML model to identify high-intent website visitors.
* Trained the classification model to predict conversion probability based on user behavioral data.
* Visualized the decision tree classifier and reduced the bias by using a random forest classifier.
* Identified the most important set of user attributes that lead to conversion, and which attributes had little or no impact.
* The model recommended next steps for business to improve website conversion.

## Loan default prediction
* Predictive classification model to assess the risk of new loan applicants and make informed decisions on home loan approvals.
* The model identified the importance of different features and ensured it performs well on unseen data sets
* The model maintained a good balance between false positives and false negatives.
* The model recommended Random Forest Classifier as the best model to predict which customers are likely to default.
